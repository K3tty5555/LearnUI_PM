# 精致感大版本：方案与分批（2026-11-21）

## 来由

用户 2026-11-21 提出：切换标签、页面跳转、按钮点击都缺微交互和动效，网站整体不够精致，要一份下一个大版本的迭代意见。第一稿只盯动效，用户觉得「还差点意思」；经前端、UI/UX、品牌与产品体验三个视角审视后重写为本方案。审视结论：**精致感七成来自静态的秩序和内容质量，三成来自动效；动效要有这个网站自己的性格。**

## 用户拍板（2026-11-21）

- 采纳本方案的主张和分批（「都按你建议来，开干吧」）。
- 首页体积预算：**先合并压缩现有代码腾地方**，实在不够再放宽。
- 知名网站 74 张预览：**换成真实网站截图**（不是标注示意图）。
- 首页两句标语（2026-11-18 拍板）不动；侧栏与大标题的重复如何处理，做出样子后再问。

## 主张

**站里的每一个动静，都能叫出名字。**（接标语「寻之于目，识美于此」：看见，然后叫出名字。）

- 外壳只用 UI 词典里收录过的效果，参数与词条一致，能链回词条；词条页注明「本站哪里用了它」。
- 动作从材质推导，不用模板：**雾散**（出现：由虚到实，不位移，只用于小面积浮层）、**落墨**（选中、确认：利落落位，不回弹）；全站只留一处**玻璃高光**作为惊喜点。
- 不进外壳的展品：磁吸按钮、光标聚光灯、自定义光标、光标拖尾、粒子、边框流光、点击涟漪、倾斜卡片、文字乱序。
- 阅读内容（文字、代码、提示词）不加动画；不引入动画库；支持「减弱动态效果」。

## 分批

### 第 0 批：静态精修（多数是缺陷，先修）

- [ ] 首页体积：合并、压缩内联代码，给后续批次腾出余量（现 375 KB / 上限 380 KB，脚本 4 / 上限 4）。
- [ ] 中文小节标题比正文右缩 10px（违反 2026-11-18「标题与正文左对齐」）；检查补上标题与正文左边缘对齐。
- [ ] 统一间距与层级：小节间距、标题到内容的距离写成规范；小节标题加重；Prompt 片段框降低视觉重量。
- [ ] 复制按钮：连点两次会卡在「已复制」；失败时抹掉中英文文字。「加入参考」英文模式不切换。先写会失败的测试再修。
- [ ] 「新」标签：60 个词条永久挂着，改为按收录日期 30 天后自动消失。
- [ ] 空分类（包装 0、文字标 0）隐藏。
- [ ] 平面设计标题中英混排：中文模式整句中文（加 `projectZh`）。
- [ ] 图注不写制作过程（「已裁去 116 像素字幕」这类移到开发日志）。
- [ ] 蒙太奇封面残留的小红书图标和拼接缝；顺查其他笔记截图。
- [ ] 知名网站 74 张预览换真实网站截图；打不开的保留原图并列清单。「来源与许可证」写明截图权利归各网站。
- [ ] 加载占位：用已有静态预览图代替白底「动效加载中…」（受首页体积约束，见第一条）。
- [ ] 零碎：搜索框清除按钮是浏览器默认蓝色；手机顶部导航被截断无提示；「已选参考」浮条盖住卡片标签；平面设计详情页原作区右侧空白。
- [ ] DESIGN.md 加「语气」一节：文言只用在门槛时刻（首页、空参考集、搜不到、404），操作文案一律白话。

### 第 1 批：三个关键时刻（按用户价值）

- 找名字：搜索命中原因白话化（「你说的『三个点』→ 它的真名是……」）；⌘K 结果加缩略图、命中词高亮、默认选中第一项；搜不到时给引导和相近词条。
- 拿走：复制后说明「可直接粘贴给 AI」；加入参考时计数跳动、手机端浮条同步、读屏播报。
- 看案例：平面设计图层拆解做成「沿纵深错开、每层浮出名字」的签名动作。
- 首屏「标本橱窗」：轮播几个标本，名字随之落定，3 秒讲清「看到它 → 叫出它」。

### 第 2 批：外壳动效（先做「动效情绪板」给用户挑方向）

- 动效规范变量（时长、缓动）写进 DESIGN.md，加检查要求过渡时长用变量；重写「减弱动态效果」规则（保留淡入淡出，覆盖页面过渡）。
- 页面跳转：150–200ms 纯淡入或不做；侧栏不动；栏目高亮由构建时输出。
- 飞入（共享元素转场）只做图片类栏目（平面设计、Logo）；UI 词典只让标题和外框过渡。
- 分段控件：纯 CSS 滑块（等宽分栏）；类型胶囊只做颜色过渡。
- 筛选重排只在点类型标签时、只用于图片类目录；词典目录只淡入淡出。
- 弹窗：原生 `showModal`，CSS 退场（Safari 看不到退场，先说明）；遮罩只渐变透明度、不加模糊。
- 悬停预取下一页 HTML（`moderate`，仅 Chromium 生效），加检查禁止激进预取。
- 样板：平面设计列表 → 详情页。

### 删掉的（审视后）

骨架屏扫光、图片由虚到实、段落滚动淡入、卡片悬停上浮、所有按钮回弹、⌘K 高亮滑动、语言切换的内容交叉淡入。

## 验收

每批：现有检查全过 + 新增检查；关键状态截图人工核对；第 2 批的动效用暂停动画后截图核对，并在 Chrome 和 Safari 真机实点。
