# 017 精致感大版本 · 第 0 批：静态精修

## 目标

用户 2026-11-21 要一份「让网站更精致」的大版本意见。第一稿只盯动效，用户觉得「还差点意思」；经前端、UI/UX、品牌与产品体验三个视角审视后重写为 [docs/polish-plan.md](../docs/polish-plan.md)。审视的共识是：精致感七成来自静态的秩序和内容质量，三成来自动效；动效要有这个网站自己的性格。用户拍板（2026-11-21）：采纳方案，先做第 0 批「静态精修」；首页体积先腾地方再说放宽；知名网站 74 张预览**换成真实网站截图**。

## 改动

- **首页体积**：UI 卡片里每张都重复的「动效加载中 / 加载失败」中英文改由 CSS 写一次；加入参考按钮文字同样改由 CSS（状态 × 语言）；内联样式构建时压缩（去注释和空白，6 个页面前几百个元素的位置尺寸前后逐一比对一致）。首页 375 KB → 359 KB（上限 380 KB）。
- **小节间距**：2026-11-18（`cadd3d1`）一条样式写了一半——`.sect, .entry-tag, .hero-sub, .guide-para,` 后面没接上大括号，和下一条「上边距清零」粘在一起，全站小节、详情页简介、栏目副标的上边距都被清零，小节标题贴着上一块。删掉残片；平面设计「原作」区上边距 18→42px。
- **中文小节标题右缩 10px**（违反 2026-11-18「标题与正文左对齐」）：中英分隔用的左边距在中文模式下清零。
- **层级**：小节标题 18px、600、墨黑；逐部件「Prompt 片段」从灰底框改为左侧细线。规矩写进 DESIGN.md（层级与间距、语气两节）。
- **复制与加入参考**：连点两次卡在「已复制」、失败时抹掉中英文文字且不恢复、平面设计 / Logo 页「复制本页 Markdown」点一次永久卡住且只有中文、「加入参考」按钮和读屏标签写死中文（读屏还念出内部编号 `entry:tilt-card`）。全部修复，按钮和读屏都跟随语言，读屏念真实名称。
- **「新」标签**：60 个词条、21 种风格永久挂着。改为记录收录日期，30 天内显示；页面带到期日，过期由页面脚本自己隐藏，不依赖重新构建。当前 31 个显示。
- **空分类**（包装 0、文字标 0）不再显示。
- **平面设计中文标题**整句中文：新增 `projectZh`（28 个），校验必填。图注去掉制作过程（截帧秒数、裁了多少像素，明细见下）。
- **蒙太奇 4 张图**：013 当时用「剪别处一块贴上去」盖小红书按钮，剪来的块里本身带图标、贴边成了直缝；4 张都从原图重做（反算半透明按钮的压暗恢复底图）。其余 28 张笔记截图四角检查无残留。
- **知名网站预览**：54 张换成各网站首页真实截图（`scripts/capture-site-screens.py`，清单 `assets/site-thumbs/SOURCE.json`）；20 张打不开或被拦截，保留原模板图并记原因。截图按 1440×900 的 1.6 比例出图、卡片顶部对齐从底部裁，避免左右裁掉 logo。「来源与许可证」写明截图权利归各网站。

- **零碎**：原作区两张图时右侧空一列（分栏排版改网格）；搜索框清除按钮浏览器默认蓝改墨灰；手机顶部导航右缘渐隐提示可横滑；「已选参考」浮条不再盖住页脚。

## 关键决策与踩坑

- **先写会失败的检查再修**：`test-text-width.py` 加标题对齐（改前 72 处）和标题间距「上方 ≥28px 且 ≥ 下方 1.5 倍」（改前 108 处）；新增 `test-feedback.py`（复制、加入参考、新标签过期、搜索命中白话；改前 16 处），已接入 CI。
- **构建补 `/UIUX` 前缀会误伤样式里的 data URI**：图标代码 `'/%3E` 被改成 `'/UIUX/%3E`，清除按钮图标失效。斜杠写成 `%2F`，样式里加了注释。
- **加了预览图首页反而先涨**：每张卡多一段 `<picture>`，抵掉了省下的文字；按钮双语标签一度让首页涨回 368 KB。最后都改成「CSS 写一次」才压下来——以后卡片上重复的文案一律走这条路。
- **截图的网络现实**：本机在国内，9 个站会被跳到中国区，固定用美国英文首页；archive.org 连不上，两个「老网站」规范（dell-1996、nintendo-2001）没截成。
- 第一稿方案里有几条把已有功能写成「新做」（复制反馈、加入参考反馈、焦点描边），审视后更正——以后写方案前先顺着用户路径实际点一遍。
